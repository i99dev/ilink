# Bundled radio discovery

Public station metadata exported from the existing app catalog on 2026-09-06. The snapshot contains 5,166 stream entries across 212 countries, up to 50 per country ordered by existing popularity votes. Playback still uses the station operator's stream.

Only station display names and public HTTP(S) stream URLs are bundled. Rows with URL userinfo, query parameters, fragments, or retired ilink/DigitalOcean hosts were excluded. No account data, backend credentials, source UUIDs, or subscriber metadata are included. Stations may change or stop broadcasting; local playlist import remains available.
