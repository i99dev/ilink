# Local mini-apps

The catalog combines bundled examples and locally installed content. Import a compatible archive, review its manifest and select supported permission scopes before installation. Catalog availability, launch and local configuration do not require an account or subscription.

- [Installation and catalog](catalog.md)
- [Security and consent](security.md)
- [Runtime architecture](architecture.md)
- [Bridge API](bridge-api.md)
- [Legacy administrator extensions](admin-permissions.md)
- [Home-screen shortcuts](home-screen-shortcuts.md)

There is no hosted mini-app catalog, upload service or automatic backend synchronization. Existing installed data is retained subject to digest verification and scope review.
